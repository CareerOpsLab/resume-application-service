# 简历定向优化与代投递 Skill

这是一个可复用的简历服务 Skill，适用于从顾客资料开始，完成目标岗位分析、定向改简历、岗位筛选和确认范围内的代投递。

## 能做什么

- 从零整理顾客的真实经历
- 拆解目标岗位 JD 和筛选关键词
- 按岗位重点重组简历内容
- 采用完整内容型 Word 简历版式
- 生成顾客填写表和岗位投递总表
- 在顾客确认后协助完成半自动投递

## 怎么使用

调用 Skill：

```text
$resume-application-service
```

然后上传：

1. 顾客填写好的 `templates/customer-intake.docx`
2. 原简历（如果有）
3. 目标岗位 JD、招聘链接或截图
4. 顾客的补充经历、作品集和限制条件

推荐提示词：

```text
$resume-application-service

请先分析，不要直接改写。
请输出：岗位要求、经历匹配点、简历问题、待补充信息和改写方向。
```

## 标准流程

资料采集 → 目标确认 → JD 分析 → 简历改写 → 顾客核对 → 简历定稿 → 岗位筛选 → 顾客确认投递范围 → 半自动或人工代投 → 更新投递总表。

顾客确认最终简历和岗位清单后，才可以开始投递。代投递完成后，把所有信息写入 `templates/application-tracker.xlsx`，发送表格链接给顾客自行查看。

## 隐私和安全

仓库中的简历模板和示例已经脱敏。不要上传真实顾客的姓名、电话、邮箱、证件照、身份证件、账号、密码、验证码或招聘平台登录信息。自动投递只能使用顾客已登录的环境，并在每个岗位提交前保留确认节点。

## 服务边界

本 Skill 不承诺 HR 沟通、投递状态追踪、面试安排、测评填写或 Offer 跟进。它只负责确认范围内的简历优化、岗位筛选、代投递和投递信息归档。

## 文件说明

- `SKILL.md`: AI 执行规则
- `references/`: JD、简历、投递和顾客资料的详细规则
- `assets/`: 脱敏简历模板和示例
- `templates/`: 顾客直接填写或查看的工作文件
