# 多岗位定向流程

适用于一次处理两个及以上相近或不同的目标岗位。

## 流程

1. 为每个 JD 建立岗位编号，提取职责、硬性条件、关键词和限制条件。
2. 建立共享经历库，标记每条经历可支持哪些岗位。
3. 生成共性缺口表，先集中向顾客追问一次。
4. 对每个岗位单独计算匹配度和简历质量分数。
5. 共享事实和经历证据，分别调整摘要、关键词顺序和重点项目。
6. 为每个岗位输出独立简历版本、评分记录和改写对照。
7. 顾客一次审核全部版本，再确认投递岗位范围。

## 规则

- 相近岗位可以共用经历库，但不能共用未经检查的最终简历。
- 差异较大的岗位必须分别制作定向版本。
- 一个岗位的低分只能触发该岗位版本的自动改写，不改动其他岗位版本。
- 批量处理不得跳过逐岗位的事实检查、评分和顾客确认。
