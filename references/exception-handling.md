# 异常处理规则

遇到以下情况先暂停对应步骤，说明事实和影响，再请求顾客确认。

| 情况 | 处理方式 |
|---|---|
| 目标岗位不明确 | 只保留一个主投方向，列出相近方向供顾客选择 |
| JD 缺少关键信息 | 标记未知项，不根据行业惯例自行补齐 |
| 经历与岗位不匹配 | 给出匹配评分和缺口，不通过改写制造匹配 |
| 顾客要求夸大或虚构 | 说明不能虚构，改为追问可验证事实 |
| 资料出现相互冲突 | 暂停相关改写，列出冲突项并请求确认 |
| 岗位链接失效或已关闭 | 标记为不可投递，不写入已投递记录 |
| 平台要求验证码、测评或隐私验证 | 交还顾客本人完成，不代答、不绕过 |
| 顾客未确认投递范围 | 只生成待投递清单，不提交岗位 |
| 超出修改或投递数量 | 暂停并重新确认范围、费用和周期 |
| 公开示例可能暴露身份 | 立即移出公开材料，改用虚构数据后再分享 |

## 标准提示

```text
当前无法继续执行：[具体原因]。
已确认的信息是：[事实]。
缺少或冲突的信息是：[问题]。
请确认：[需要顾客做出的选择]。
```
